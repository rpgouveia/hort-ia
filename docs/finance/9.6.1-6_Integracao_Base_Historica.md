> **Entregável:** 9.6.1-6 Integrar o motor de previsão com a base de dados históricos (via API)
> **Pacote de trabalho:** 9.6.1 · **Marco:** M9.6 · **Responsável:** Jafte Fagundes
> **Versão 1.0 — 03/11/2026**
> **Status:** aguardando revisão da PR. **A integração com a API real está pendente da equipe de Planejamento Financeiro**

## 1. Decisão

Até a Daily de 03/11/2026, a equipe de Planejamento Financeiro não enviou a API nem os dados pedidos na proposta de 10/10/2026. Na daily, Jafte definiu **mockar** a integração para não travar o pacote. Isso responde à pendência da Retrospective do Sprint 1 sobre a Conab concluir ou não este item:

- **Concluído:** o motor lê a série por API, com contrato validado e testado por HTTP real, servido por um mock.
- **Não concluído:** a conexão com a API real. Quando ela existir, basta apontar a variável de ambiente, se o contrato for mantido, ou adaptar `history.py`, se mudar.

## 2. Contrato

```
GET {HORTIA_FINANCE_HISTORY_URL}/history/prices

{"source": {"id": "...", "title": "...", "publisher": "..."},
 "prices": [{"product_id": "alface", "entrepost_id": "ceagesp_sp", "month": "2026-08", "price_brl_kg": 3.23}]}
```

O contrato é uma proposta nossa e ainda não foi validado pela equipe de Planejamento Financeiro nem por 9.7.2-3.

| Situação | Comportamento |
|---|---|
| Variável não definida | Lê os arquivos da Conab (`data/market/`), como antes |
| API responde dentro do contrato | Usa os preços da API. O campo `source` da previsão traz o id informado pela API |
| Fora do ar, JSON inválido, preço não positivo, mês inválido, id desconhecido, duplicata ou lista vazia | Registra um aviso no log e usa os arquivos da Conab. O campo `source` continua indicando a Conab |

A série é lida ao carregar o serviço. Uma atualização na API, ou a volta dela depois de uma queda, só vale após reiniciar o serviço.

## 3. Como rodar o mock

```bash
uv run uvicorn hort_ia.finance.mock_history_api:app --port 8090
HORTIA_FINANCE_HISTORY_URL=http://localhost:8090 uv run uvicorn hort_ia.api.main:app --port 8080
```

O mock serve a série da Conab e se identifica como `mock_finance_history_api`, de modo que nenhuma previsão gerada a partir dele se passa por dado real da integração.
