## 1. Contexto e Objetivo

O microsserviço **Hort-IA** deve estar empacotado e disponibilizado de forma padronizada para consumo imediato pelos 4 módulos da plataforma (Assistência Técnica, Comercialização, Gestão de Operação e Planejamento Financeiro), construídos em Java/Spring Boot.

A publicação do serviço em ambiente piloto garante a reprodutibilidade da infraestrutura de IA, isolamento de dependências nativas (PyTorch, OpenCV) e facilidade de integração local ou em nuvem.

---

## 2. Estratégia de Empacotamento em Contêiner (Docker)

Foi configurado um `Dockerfile` multi-stage com base Debian Slim e `uv`, assegurando imagens leves e seguras:

1. **Estágio Builder:** Compila e sincroniza as dependências exatas a partir do `uv.lock`.
2. **Estágio Runner:**
   - Instala bibliotecas de runtime mínimas para visão computacional (`libgl1`, `libglib2.0-0`, `curl`).
   - Copia o ambiente virtual otimizado e os datasets versionados (`data/knowledge`, `data/market`).
   - Executa sob usuário não-root (`appuser`), em conformidade com as boas práticas de segurança.
   - Fornece sonda de verificação de integridade (*HEALTHCHECK*) na rota `/`.

---

## 3. Instruções de Execução do Piloto

### Opção A: Execução via Docker (Recomendada para os parceiros Java/Spring Boot)

```bash
# 1. Construir a imagem do contêiner piloto
docker build -t hort-ia-api:latest .

# 2. Executar o contêiner expondo a porta 8080
docker run -d -p 8080:8080 --name hort-ia-service hort-ia-api:latest

# 3. Testar a disponibilidade da API
curl http://localhost:8080/
```

### Opção B: Execução Direta via Python / Uvicorn

```bash
# Execução direta com recarregamento
uv run uvicorn hort_ia.api.main:app --host 0.0.0.0 --port 8080
```

## 4. Endpoints e Documentação Interativa

Uma vez publicado o contêiner piloto, os desenvolvedores dos módulos clientes podem testar todos os contratos através de:
- **Swagger UI (OpenAPI):** `http://localhost:8080/docs`
- **ReDoc:** `http://localhost:8080/redoc`
- **Especificação OpenAPI JSON:** `http://localhost:8080/openapi.json`
