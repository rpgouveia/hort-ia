## 1. Contexto e Decisão Arquitetural

Em consonância com a Nota de Replanejamento do Gantt (v7 de 10/10/2026):
> *"Fila retirada do escopo (backlog); mantido cache simples."*

As aplicações consumidoras (Web e Mobile para agricultores urbanos e técnicos extensionistas) operam frequentemente em locais de periferia urbana ou áreas periurbanas com cobertura celular intermitente (redes 2G/EDGE e 3G instáveis).

Para garantir respostas rápidas, economia de franquia de dados e operação resiliente, foram implementadas políticas formais de cache HTTP na camada de borda do FastAPI e especificadas as diretrizes de cache no cliente.

---

## 2. Estratégia de Cache HTTP nos Endpoints

Conforme os princípios de *Design by Contract (DbC)* detalhados em `9.7.1-2`, os cabeçalhos de resposta foram configurados para direcionar caches intermediários (gateways/proxies) e armazenamento local nas aplicações móveis:

| Rota | Tipo de Dado | Cabeçalho `Cache-Control` | Duração | Justificativa |
| :--- | :--- | :--- | :--- | :--- |
| `GET /recommender/planting-calendar` | Base Agronômica Embrapa | `public, max-age=86400` | 24 horas | Janelas de plantio são estáticas ou mudam raramente. |
| `GET /recommender/companion-crops` | Matriz de Consórcio | `public, max-age=86400` | 24 horas | Relações biológicas de consórcio são perenes. |
| `GET /recommender/what-to-plant` | Calendário Mensal | `public, max-age=86400` | 24 horas | Recomendações sazonais têm periodicidade mensal. |
| `GET /market/reference-price` | Cotações Conab / Ceasa | `public, max-age=3600` | 1 hora | Cotações diárias são consolidadas no atacado. |

---

## 3. Implementação Técnica no Código

A injeção do cabeçalho é realizada diretamente no objeto `fastapi.Response` nos módulos:
* `src/hort_ia/api/recommender.py`:
  ```python
  response.headers["Cache-Control"] = "public, max-age=86400"
  ```
* `src/hort_ia/api/market.py`:
  ```python
  response.headers["Cache-Control"] = "public, max-age=3600"
  ```

---

## 4. Validação Automatizada

A eficácia dos cabeçalhos de cache é testada continuamente na suíte de testes de contratos da API:
* Arquivo de teste: `tests/test_api_contracts.py`
* Caso de teste: `test_cache_control_headers_offline_support`
* Critério: Requisições bem-sucedidas aos endpoints estáticos e comerciais obrigatoriamente retornam a diretiva de cache configurada.
