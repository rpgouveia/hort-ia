## 1. Visão Geral do Catálogo de Serviços

Este documento estabelece o contrato formal de integração (*API Contract*) entre o microsserviço **Hort-IA** e os quatro módulos parceiros da plataforma. Todos os schemas são mapeados diretamente para classes **Pydantic v2** e compatíveis com a especificação **OpenAPI 3.1** (disponível interativamente na rota `/docs`).

### Tabela Resumo dos Endpoints

| Método | Rota | Módulo / Domínio | Módulo Consumidor Principal |
| :---: | :--- | :--- | :--- |
| `POST` | `/cv/validate` | Visão Computacional | Assistência Técnica Digital |
| `POST` | `/cv/preprocess` | Visão Computacional | Assistência Técnica Digital |
| `GET` | `/finance/price-forecast` | Modelos Preditivos | Planejamento Financeiro |

### 2.1. Visão Computacional: Validação de Qualidade
* **Rota:** `POST /cv/validate`
* **Finalidade:** Avaliar iluminação, nitidez e contraste da fotografia de folha antes do diagnóstico, prevenindo processamento de imagens ruins.
* **Content-Type:** `multipart/form-data`

#### Parâmetros de Entrada:
* `file`: Arquivo de imagem binário (JPEG, PNG ou WebP).

#### Resposta de Sucesso (`200 OK`):
```json
{
  "is_valid": true,
  "rejection_reasons": [],
  "blur_score": 142.5,
  "brightness_score": 118.2,
  "contrast_score": 45.8,
  "dimensions": [1080, 1920],
  "user_feedback": "A foto está nítida e bem iluminada. Pode prosseguir com o diagnóstico."
}
```

#### Resposta de Violação de Qualidade (`200 OK` com `is_valid: false`):
```json
{
  "is_valid": false,
  "rejection_reasons": ["Foto borrada ou fora de foco."],
  "blur_score": 38.4,
  "brightness_score": 95.0,
  "contrast_score": 25.1,
  "dimensions": [720, 1280],
  "user_feedback": "A imagem está fora de foco. Toque na tela para focar a câmera antes de tirar a foto."
}
```

#### Exemplo cURL:
```bash
curl -X POST "http://localhost:8080/cv/validate" \
  -F "file=@folha_tomate.jpg;type=image/jpeg"
```

### 2.2. Visão Computacional: Pré-processamento e Padronização
* **Rota:** `POST /cv/preprocess`
* **Finalidade:** Validar qualidade, redimensionar para 224x224 RGB e remover metadados EXIF/GPS em conformidade com a LGPD.
* **Content-Type:** `multipart/form-data`

#### Resposta de Sucesso (`200 OK`):
```json
{
  "width": 224,
  "height": 224,
  "channels": 3,
  "size_bytes": 18450,
  "format": "JPEG",
  "metadata_stripped": true
}
```

#### Resposta de Erro de Tipo Não Suportado (`415 Unsupported Media Type`):
```json
{
  "detail": "O arquivo enviado não é uma imagem válida (use JPEG, PNG ou WebP)."
}
```

### 2.3. Modelos Preditivos Financeiros: Previsão de Preços
* **Rota:** `GET /finance/price-forecast`
* **Finalidade:** Projetar o preço de atacado (R$/kg) da Conab para horizontes de 1 e 3 meses à frente.

#### Parâmetros de Entrada (Query String):
* `product_id` (string, obrigatório): ID do produto (`alface`, `batata`, `cebola`, `cenoura`, `tomate`).
* `entrepost_id` (string, obrigatório): ID do entreposto (ex.: `ceagesp_sp`, `ceasa_curitiba_pr`).
* `horizon_months` (int, opcional, padrão `1`): Horizonte de projeção (`1` ou `3`).

#### Resposta de Sucesso (`200 OK`):
```json
{
  "product_id": "alface",
  "entrepost_id": "ceagesp_sp",
  "horizon_months": 1,
  "reference_month": "2026-08",
  "target_month": "2026-09",
  "last_price_brl_kg": 4.50,
  "forecast_price_brl_kg": 4.82,
  "change_pct": 0.0711,
  "lower_brl_kg": 4.10,
  "upper_brl_kg": 5.54,
  "method": "ses",
  "validation_mape": 0.142,
  "source": "conab_boletim_hortigranjeiro",
  "model_version": "1.0.0",
  "degraded": false,
  "warning": null
}
```

#### Resposta de Erro de Horizonte Não Suportado (`422 Unprocessable Entity`):
```json
{
  "detail": "horizon must be 1 or 3 months, got 6"
}
```

#### Exemplo cURL:
```bash
curl "http://localhost:8080/finance/price-forecast?product_id=alface&entrepost_id=ceagesp_sp&horizon_months=1"
```

### 2.6. Recomendação Agronômica: O Que Plantar no Mês Atual
* **Rota:** `GET /recommender/what-to-plant`
* **Finalidade:** Recomendar a lista de hortaliças ideais para semeadura dado o mês do ano e a região.
* **Origem da lista:** o motor de recomendação (9.3.1-4), sem culturas plantadas nem cultura anterior. O contrato e a ordem alfabética foram mantidos; para a lista ordenada, com motivos e fontes, ver 2.9.

#### Parâmetros de Entrada (Query String):
* `month` (int, obrigatório): Mês atual (1 a 12).
* `ibge_code` (int/string, opcional): Código IBGE do município (ex.: `4106902` - Curitiba).
* `region` (string, opcional): Macrorregião do Brasil.
* `small_space` (bool, opcional, padrão `false`): Filtrar apenas culturas adequadas para pequenos espaços / vasos.

#### Resposta de Sucesso (`200 OK`):

```json
  "recommended_crops": [
    {
      "crop_id": "abobrinha",

      "crop_id": "alface",
      "crop_name_pt": "Alface",
      "family": "Asteraceae",
      "cycle_days": "50 a 80 dias"
    }
  ],
  "source": "embrapa_ct_47_hortalicas",
  "model_version": "1.0.0"
}
```

### 2.7. Assistente Conversacional (NLP / Chatbot Especialista)
* **Rota:** `POST /nlp/answer`
* **Finalidade:** Processar intenções e gerar respostas formatadas em linguagem acessível com fontes citadas e sinalização de handoff quando aplicável.
* **Content-Type:** `application/json`
* **Uso:** para quem já sabe a intenção (um botão "Quando plantar?", por exemplo). Para o texto digitado pelo usuário, ver 2.10.

#### Campos de Entrada:
* `intent` (string, obrigatório): `planting_time`, `what_to_plant`, `crop_care`, `companion_planting`, `pest_disease`, `market_price`, `help` ou `fallback`. Outro valor retorna `422`.
* `crop_id` (string, opcional): cultura (`planting_time`, `crop_care`, `companion_planting`).
* `ibge_code` (int, opcional) ou `region` (string, opcional): localização; `ibge_code` tem prioridade.
* `month` (int, opcional, padrão: mês corrente): 1 a 12.
* `aspect` (string, opcional): `spacing`, `harvest`, `watering` ou `container` (`crop_care`).
* `small_space` (bool, opcional): só culturas para vaso (`what_to_plant`).
* `rotation` (bool, opcional): pergunta sobre o que plantar depois (`companion_planting`).
* `cv_label` ou `entry_id` (string, opcional): praga ou doença (`pest_disease`).
* `product` e `uf` (string, opcional): produto e estado (`market_price`).

#### Payload de Entrada (`Request Body`):
```json
{
  "intent": "planting_time",
  "crop_id": "alface",
  "ibge_code": 4106902,
  "month": 10
}
```

#### Resposta de Sucesso (`200 OK`):
```json
{
  "intent": "planting_time",
  "text": "Alface de inverno no Sul: dá para plantar de fevereiro a outubro. Alface de verão no Sul: dá para plantar o ano todo. Agora em outubro está na época. A colheita começa de 50 a 80 dias depois do plantio.",
  "sources": [
    "Catálogo brasileiro de hortaliças: saiba como plantar e aproveitar 50 das espécies mais comercializadas no país, p. 13"
  ],
  "handoff": false,
  "missing_entity": null
}
```

#### Resposta com Handoff Ativo (Ausência de Dados Oficiais):
Exemplo: `{"intent": "planting_time", "crop_id": "manjericao", "region": "norte", "month": 10}`.
```json
{
  "intent": "planting_time",
  "text": "Não tenho a época de plantio de manjericão no Norte. Para isso, o melhor é falar com a Assistência Técnica.",
  "sources": [],
  "handoff": true,
  "missing_entity": null
}
```

> **Nota sobre `text`:** nas respostas de praga ou doença (`pest_disease`), o campo `text` pode conter quebras de linha (`\n`), uma parte por linha, e ações como itens de lista iniciados por `- `. A interface deve preservar essas quebras ao exibir o texto (em Markdown, uma linha simples é unida à anterior). As demais intenções vêm num parágrafo só.

### 2.9. Recomendação Agronômica: Recomendações por Perfil da Horta
* **Rota:** `POST /recommender/recommendations`
* **Finalidade:** Recomendar o que plantar agora para uma horta específica, em ordem, com os motivos e as fontes de cada sugestão. É o entregável do pacote 9.3.1 ("função/endpoint que recebe um perfil de usuário e retorna uma lista de recomendações").
* **Abordagem:** baseada em conhecimento: filtros de época, região, pequeno espaço, cultura já plantada e rotação por família, seguidos de pontuação por plantas companheiras. Registro de decisão: `docs/recommender/9.3.1-3_Abordagem_Motor_Recomendacao.md`.
* **Content-Type:** `application/json`

#### Payload de Entrada (`Request Body`):
```json
{
  "ibge_code": 4106902,
  "month": 11,
  "small_space": true,
  "planted": ["tomate"],
  "previous_crop": null
}
```
* `ibge_code` (int, opcional) ou `region` (string, opcional): um dos dois é obrigatório; `ibge_code` tem prioridade.
* `month` (int, opcional, padrão: mês corrente): 1 a 12.
* `small_space` (bool, opcional, padrão `false`): só culturas indicadas para vaso e pouco espaço.
* `planted` (lista de ids, opcional): culturas que estão na horta agora. Entram no consórcio e saem da lista.
* `previous_crop` (string, opcional): última cultura do canteiro. Culturas da mesma família saem da lista (rotação).

#### Resposta de Sucesso (`200 OK`), abreviada:
```json
{
  "region": "sul",
  "month": 11,
  "small_space": true,
  "recommendations": [
    {
      "rank": 1,
      "crop_id": "manjericao",
      "crop_name_pt": "Manjericão",
      "score": 1.5,
      "variants": [],
      "reasons": [
        {"code": "in_season", "text": "No Sul, dá para plantar de novembro a dezembro.", "source": "…"},
        {"code": "season_ending", "text": "A época de plantio termina em dezembro.", "source": "…"},
        {"code": "companion_good", "text": "Combina com tomate (indicação tradicional).", "source": "Companion Plants"},
        {"code": "pest_repellent", "text": "Ajuda a afastar pragas das outras plantas da horta.", "source": "…"}
      ],
      "warnings": []
    }
  ],
  "excluded": [
    {"crop_id": "tomate", "reason": "already_planted"},
    {"crop_id": "batata", "reason": "not_for_small_space"}
  ],
  "warnings": [],
  "approach": "knowledge_based",
  "model_version": "1.0.0"
}
```
* `recommendations`: em ordem; `score` soma +1 por cultura plantada que combina, −1 por cultura que não combina e +0,5 para planta repelente. Cada item tem ao menos o motivo `in_season`, com fonte.
* `warnings` de cada item: plantas que não combinam (`companion_bad`). A cultura continua na lista, mais abaixo.
* `excluded`: cada cultura que não entrou, com o motivo: `no_region_data`, `out_of_season`, `not_for_small_space`, `no_small_space_info`, `already_planted` ou `same_family_as_previous`. Não precisa ser exibido.
* `warnings` do resultado: culturas do perfil que a base não conhece (por exemplo, mandioca), ignoradas.
* `model_version`: muda quando um filtro, peso ou critério de ordem mudar. Guardar junto da avaliação "útil / não útil" do usuário.

#### Erros:
* `422`: código IBGE ou região inválidos, sem localização, ou mês fora de 1 a 12.

### 2.10. Assistente Conversacional: Mensagem em Texto Livre
* **Rota:** `POST /nlp/message`
* **Finalidade:** Responder a mensagem digitada pelo usuário: entende a intenção e as entidades, decide se responde, confirma, pergunta de volta ou encaminha, e responde com os mesmos textos de 2.7. É o entregável do pacote 9.4.1 ("motor capaz de receber uma mensagem de texto e retornar uma resposta coerente").
* **Abordagem:** registro de decisão em `docs/nlu/9.4.1-3_Abordagem_Motor_Conversacional.md`.
* **Content-Type:** `application/json`
* **Sem estado:** o servidor não guarda a conversa. Cada resposta traz um `context`, que o cliente devolve, sem alterar, na mensagem seguinte da mesma conversa. O `context` contém só identificadores (intenção, cultura, pergunta pendente), nunca o texto do usuário.

#### Payload de Entrada (`Request Body`):
```json
{
  "text": "quando eu planto?",
  "ibge_code": 4106902,
  "small_space": false,
  "cv_label": null,
  "month": null,
  "context": null
}
```
* `text` (string, obrigatório, 1 a 500 caracteres): a mensagem como o usuário escreveu.
* `ibge_code` (int, opcional): município da horta, do perfil. Um lugar citado na mensagem tem prioridade.
* `small_space` (bool, opcional): a horta é em vaso ou pouco espaço.
* `cv_label` (string, opcional): rótulo do modelo de visão computacional, quando a mensagem vem com foto. Nesse caso a resposta é sobre a praga ou doença e o texto não é classificado.
* `month` (int, opcional, padrão: mês corrente): só para testes.
* `context` (objeto, opcional): o `context` da resposta anterior; `null` na primeira mensagem.

#### Resposta de Sucesso (`200 OK`): pergunta de volta
```json
{
  "intent": "planting_time",
  "text": "De qual planta você está falando?",
  "sources": [],
  "handoff": false,
  "missing_entity": "crop",
  "decision": "ask",
  "confidence": 0.9713,
  "entities": {"crop": null, "region": "sul", "uf": "PR", "month": 11, "care_aspect": null, "rotation": false, "small_space": false},
  "context": {
    "version": 1,
    "last_intent": "planting_time",
    "crop": null,
    "pending": {"type": "entity", "intent": "planting_time", "entity": "crop", "attempts": 1, "slots": {"…": "…"}}
  }
}
```

#### Mensagem Seguinte e Resposta:
Requisição com `"text": "alface"` e o `context` acima:
```json
{
  "intent": "planting_time",
  "text": "Alface de inverno no Sul: dá para plantar de fevereiro a outubro. Alface de verão no Sul: dá para plantar o ano todo. Agora em novembro está na época. A colheita começa de 50 a 80 dias depois do plantio.",
  "sources": ["Catálogo brasileiro de hortaliças: saiba como plantar e aproveitar 50 das espécies mais comercializadas no país, p. 13"],
  "handoff": false,
  "missing_entity": null,
  "decision": "answer",
  "confidence": null,
  "entities": {"crop": "alface", "region": "sul", "uf": "PR", "month": 11, "care_aspect": null, "rotation": false, "small_space": false},
  "context": {"version": 1, "last_intent": "planting_time", "crop": "alface", "pending": null}
}
```

#### Campos da Resposta:
* Os campos de 2.7 (`intent`, `text`, `sources`, `handoff`, `missing_entity`), mais:
  * `text` segue a nota de 2.7: nas respostas de praga ou doença pode conter quebras de linha (`\n`) e itens de lista, que a interface deve preservar.
* `decision`: o que a interface pode mostrar.
  * `answer`: resposta final.
  * `confirm`: pergunta de sim ou não ("Você quis dizer alface?"). Sugere botões Sim/Não.
  * `ask`: pergunta que pede uma resposta curta (a planta, o lugar, o assunto).
  * `fallback`: fora do que o assistente sabe, com `handoff: true`.
* `intent`: `clarify` quando o assistente pergunta o assunto antes de saber a intenção.
* `confidence`: confiança do classificador na mensagem, ou `null` quando a mensagem foi lida como resposta a uma pergunta pendente ou veio com foto.
* `entities`: o que foi usado para responder.
* `context`: devolver na mensagem seguinte. Para começar uma conversa nova, enviar `null`.

#### Erros:
* `422`: `text` vazio ou com mais de 500 caracteres, código IBGE inválido, mês fora de 1 a 12, ou `context` de outra versão.

#### Recomendações de Integração:
* Reaproveitar a conexão HTTP (*keep-alive* ou HTTP/2) e usar TLS 1.3. Em 2G, a média por mensagem cai de 3,3 s (conexão HTTPS nova a cada mensagem) para 1,0 s (`docs/nlu/9.4.2-4_Validacao_Tempo_Conexao_Lenta.md`).
* Guardar o `context` por conversa no módulo consumidor, sem interpretá-lo; o formato pode mudar entre versões (campo `version`).

Estes contratos eliminam ambiguidades de integração e fornecem a especificação necessária para a implementação das rotas em código no pacote **9.7.2**.

As seções 2.9 e 2.10 registram as rotas que expõem os motores das entregas **9.3** (recomendação por perfil, 9.3.1-5) e **9.4** (assistente em texto livre, 9.4.1-5 e 9.4.1-7). A integração dessas rotas com as bases do módulo é verificada pelos testes de 9.3.2-3 e 9.4.2-3.
