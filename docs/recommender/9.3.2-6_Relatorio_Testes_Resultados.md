## 7. Limitações e lacunas conhecidas

Já identificadas antes do UAT; acrescentar as que o UAT revelar.

| Lacuna | Efeito | Encaminhamento |
|---|---|---|
| Manejo de pragas e doenças por grupo, ainda em rascunho (CT 47 e HPE) | 20 das 22 identificações de praga ou doença passam a orientar prevenção ("O que ajuda:"); o tratamento continua encaminhado à Assistência Técnica, e caldas e preparados não aparecem até a revisão. Tesourinhas e gorgulhos seguem sem orientação | Revisão da base com agrônomos (9.4.1-9) |
| Queima-das-folhas do morango sem nome popular | A resposta usa o nome científico | Idem |
| Morango, repolho e abobrinha sem informação de pouco espaço | Ficam fora da lista quando `small_space` está ligado | Idem |
| Adubação sem intenção no assistente (citada no levantamento de 9.7.1-1) | Pergunta sobre adubo cai no encaminhamento | Próxima versão da base e do dataset |
| Consórcio só com evidência tradicional | Ordena a lista, nunca exclui; a resposta avisa | — |
| Pesos do motor (1,0 e 0,5) e limiares do assistente (0,3 e 0,5) arbitrados | Podem não refletir o que o usuário acha útil | Recalibrar com os dados do UAT |
| "O que plantar além do tomate?" vira época do tomate (regra da entidade) | Resposta fora do pedido | Observar no conjunto de teste; tratar com termos de exclusão se recorrente |
| Cultura já plantada sempre excluída | Esconde o plantio escalonado | Virar aviso se o UAT apontar |
| Requisito do TAP sobre informações da comunidade | Parcialmente atendido no MVP (sem histórico) | Etapa colaborativa futura, com as avaliações do UAT |
| Amostra do UAT | Com 5 participantes, cada um pesa 20% das notas | Ler as médias junto dos comentários |
| A identificação por foto não mostra o sintoma esperado | A pessoa não consegue conferir se o modelo acertou antes de seguir a orientação | Implementado em feat/pest-symptoms para as 10 entradas com sintoma; fungos e bactérias dependem dos agrônomos |

## 9. Como reproduzir os números

```bash
uv run pytest                                          # suíte completa
uv run pytest tests/test_recommender_engine.py tests/test_recommender_integration.py \
  tests/test_knowledge_base.py tests/test_geo.py      # seção 3
uv run pytest tests/test_nlu_*.py                      # seção 4
uv run --with coverage coverage run --source=src/hort_ia/recommender,src/hort_ia/nlp -m pytest \
  tests/test_recommender_*.py tests/test_nlu_*.py
uv run --with coverage coverage report                 # cobertura
uv run python scripts/measure_slow_connection.py       # tempo em conexão lenta (alguns minutos)
uv run python scripts/evaluate_nlu_engine.py           # seção 5
uv run python scripts/uat_session.py summary           # seção 6, na máquina da sessão
```
